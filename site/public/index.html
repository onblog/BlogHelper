喵喵吧台

把剪贴板里乱糟糟的内容，变成你下一步要用的样子

截个图、复制一段文字——点一下菜单栏，清理干净、排好版、整理成能直接粘的样子。 图片直接改，也能传进你自己的图床。

macOS 12+ · 最新版本 v— · 首次打开需右键 → 打开 · 匿名统计可在设置关闭

21 个动作，六个分组

面板不会把所有功能都摊在你脸上：剪贴板是图片就只出图片动作，是普通文字就不会出现「转纯文本」。

格式转换

  • 转纯文本（剥掉格式，只剩字）
  • 转 Markdown（带格式的文字 → 干净源码）
  • 转富文本（Markdown → 带格式，粘进 Word/微信）

清理

  • 去首尾空白 · 合并空行
  • 去掉行号 · 压成一行
  • 清除隐形字符（零宽、BOM）
  • 去掉 Markdown 标记

中文排版

  • 中英文之间自动加空格
  • 标点转全角

列表整理

  • 去重行 · 排序行

链接

  • 净化链接（去掉 utm_* 跟踪参数）
  • 提取文中所有链接

图片

  • 上传到图床 → 链接
  • 复制到剪贴板 · 存到下载目录

三个顺手的小细节

默认白天营业

  • 奶油纸 + 焦糖墨，点开像张便签
  • 右上角的小太阳可以换成打烊的炭黑
  • 手动切换、记住选择，不跟随系统

图片三件事

  • 复制到剪贴板，随时贴进别的应用
  • 预览打开图片，用系统「预览」随手改
  • 存到下载目录，或上传到自己的图床

改完直接覆盖剪贴板

  • 文字点「编辑」改字；图片能裁剪、打码、画笔、箭头
  • 保存即覆盖剪贴板，⌘↵ 快速保存
  • ⌥⌘Z 可以撤销这次覆盖

图片存在你自己的桶里

没有官方图床，也没有账号。填一个 S3 兼容存储，链接就指向你自己的域名，费用和隐私都归你。

字段 填什么
Endpoint https://<account-id>.r2.cloudflarestorage.com（R2）
https://cos.<region>.myqcloud.com（COS）
https://oss-<region>.aliyuncs.com（OSS）
Region R2 填 auto，COS/OSS 填真实地域
桶名 你的存储桶名称
公开域名 图片对外服务的域名，回给你的链接就用它
Access Key / Secret 有写权限的 S3 密钥；Secret 用 macOS 钥匙串加密

R2 最省：10 GB 免费、不收流出流量费。对象名按内容寻址，同一张图传两次只有一个文件。

常见问题

双击提示「未验证的开发者」怎么办？

安装包是 ad-hoc 签名、没做 Apple 公证。在访达里右键图标 → 打开 → 再点一次「打开」即可； 也可以在「系统设置 → 隐私与安全性」里选仍要打开。

它是怎么记录剪贴板历史的？

macOS 没有剪贴板变更事件，只能轮询：文字每 1.2 秒读一次并比对哈希，图片每 3 秒采样一次、 且只在剪贴板没有文字时才读。副作用是连拍两张图时，第二张可能不会被记录。

数据存在哪？会上传吗？

历史存在本机 ~/Library/Application Support/喵喵吧台/，图片是一个索引加若干文件。 网络请求只有两类：图片 PUT 到你配置的存储桶，以及每次启动一条匿名信号（随机设备 ID + 城市级定位，可在设置关闭）。

需要什么系统权限？

完全不需要系统权限：⌥⌘V 呼出面板，文字与图片处理都直接可用。截图交给 macOS 自带的 ⌘⇧⌃4（直接进剪贴板），喵喵吧台只负责把它变成你要的样子。
