吧台

把剪贴板里乱糟糟的内容，变成你下一步要用的样子

截个图、复制一段网页、抄一列名单——点一下菜单栏，清理干净、排好版、整理成能直接粘的样子。 图片就传进你自己的图床。

macOS 12+ · 8 线程分片下载 · 首次打开需右键 → 打开 · 不收集任何数据

23 个动作，六个分组

面板不会把所有功能都摊在你脸上：剪贴板是图片就只出图片动作，是普通文字就不会出现「转纯文本」。

格式转换

  • 转纯文本（剥掉网页样式）
  • 转 Markdown（网页/Word → 干净源码）
  • 转富文本（Markdown → 带格式，粘进 Word/微信）

清理

  • 去首尾空白 · 合并空行 · 删掉空行
  • 去掉行号 · 压成一行
  • 清除隐形字符（零宽、BOM）
  • 去掉 Markdown 标记

中文排版

  • 中英文之间自动加空格
  • 标点转全角
  • 标点转半角

列表整理

  • 去重行 · 排序行 · 反转行序
  • 加序号
  • 合并成逗号分隔

链接

  • 净化链接（去掉 utm_* 跟踪参数）
  • 链接里的 %20 解码
  • 提取文中所有链接

图片

  • 上传到图床 → 链接
  • 存到下载目录

两个顺手的小细节

两套外观

  • 深色：打烊后的吧台，炭黑与琥珀
  • 浅色：白天营业，奶油纸与焦糖墨
  • 手动切换、记住选择，不跟随系统

截图到剪贴板

  • ⌥⌘S 调起系统自带的框选器
  • 截完就落在剪贴板，面板自动弹开
  • 下一次点击就能传到图床拿链接

直接改剪贴板

  • 文字预览上点「编辑」，手动改字
  • 保存即覆盖剪贴板，⌘↵ 快速保存
  • ⌥⌘Z 可以撤销这次覆盖

图片存在你自己的桶里

没有官方图床，也没有账号。填一个 S3 兼容存储，链接就指向你自己的域名，费用和隐私都归你。

字段 填什么
Endpoint https://<account-id>.r2.cloudflarestorage.com（R2）
https://cos.<region>.myqcloud.com（COS）
https://oss-<region>.aliyuncs.com（OSS）
Region R2 填 auto，COS/OSS 填真实地域
桶名 你的存储桶名称
公开域名 图片对外服务的域名，回给你的链接就用它
Access Key / Secret 有写权限的 S3 密钥；Secret 用 macOS 钥匙串加密

R2 最省：10 GB 免费、不收流出流量费。对象名按内容寻址，同一张图传两次只有一个文件。

常见问题

双击提示「未验证的开发者」怎么办？

安装包是 ad-hoc 签名、没做 Apple 公证。在访达里右键图标 → 打开 → 再点一次「打开」即可； 也可以在「系统设置 → 隐私与安全性」里选仍要打开。

它是怎么记录剪贴板历史的？

macOS 没有剪贴板变更事件，只能轮询：文字每 1.2 秒读一次并比对哈希，图片每 3 秒采样一次、 且只在剪贴板没有文字时才读。副作用是连拍两张图时，第二张可能不会被记录。

数据存在哪？会上传吗？

历史存在本机 ~/Library/Application Support/bar-tool/，图片是一个索引加若干文件。 应用唯一的网络请求，就是把图片 PUT 到你配置的存储桶；没有统计、没有崩溃上报。

需要什么系统权限？

功能本身不需要权限：⌥⌘V 呼出面板、文字与图片处理都直接可用。只有「截图」这个功能要授权 「屏幕录制」，系统框选器也因此只会出现在你按下 ⌥⌘S 的时候。
